Car Sales Dashboard – Power BI

Project Overview

This project is an interactive Power BI dashboard analyzing car sales data from a dealership. The dashboard helps stakeholders track sales performance, identify trends, and make data-driven decisions.

Key Features

- Total Cars Sold (YTD): 2,620 vehicles
- Year-over-Year Growth: 19.73%
- Sales breakdown by: Body Style, Color, Region
- Interactive Filters: Drill down by dealer, region, or time period

Tools Used

Power BI Dashboard - development and visualization 
Power Query - Data cleaning and transformation 
DAX - Calculations (YTD, Year-on-year(YoY) Growth, Total Sales) Excel - Initial data exploration


Key Insights

-Top Body Style: SUV
-Top Color: Pale White
-Top Region: Austin
-Average Price: $28.0K
-Growth Trend: Sales increased 19.73%  year-over-year

How to View

1. Download the .pbix file from this repository
2. Open in Power BI Desktop (free download from Microsoft)
3. Explore the interactive dashboard

About the Data

The dataset contains 5,000+ car sales transactions with details including:
- Car model, body style, color, price
- Dealer region, customer gender, annual income
- Sale date, engine type, transmission

Future Improvements
